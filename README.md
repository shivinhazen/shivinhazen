# 👨‍💻 Lucas Leão  
### Desenvolvedor Front‑End

Desenvolvedor front-end com foco em aplicações web modernas. Curso Engenharia de Software e trabalho com tecnologias como React, JavaScript (ES6+) e CSS3.

Com base no Rio de Janeiro, atuo desde a criação de interfaces até a gestão de dados no front-end. Aplico arquitetura baseada em componentes, otimizações de performance e práticas de acessibilidade.

Mantenho o código limpo, organizado e acompanho constantemente as ferramentas e padrões mais atuais do mercado.
